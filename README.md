# Anime Explorer 

## Cloning a repo with submodules
```bash
$ git submodule update --init --recursive
```


## Frontend 

### Prerequisite
- NodeJS

### How to run
```bash
$ cd frontend
$ npm i 
$ npm run dev
```


## Backend 

### Prerequisite
- Python3

### How to run
```bash
$ cd backend
$ pip install -r requirements.txt
$ fastapi dev main.py
```
